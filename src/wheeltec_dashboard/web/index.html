3D 视图 (three.js · 雷达 · 机器人模型 · SLAM 地图)

图层：Grid / 坐标轴 / LaserScan(/scan) / Odom 轨迹 / 机器人模型(URDF) / SLAM 地图(/map)。TF 直接订阅 /tf+/tf_static，无需 tf2_web_republisher。机器人模型：经 rosbridge 调 URDF 节点的 get_parameters 取已展开的 robot_description，浏览器解析后按每个 link 的实时 TF 摆放；网格文件（STL/DAE）由面板 HTTP 服务的 /pkg/<包名>/… 路由提供（重编译 wheeltec_dashboard 生效）。机械臂模型若由独立的 robot_state_publisher 发布，在"URDF 节点"里用逗号补上其节点名即可。SLAM 地图：复用 VLA 子页的 /map 数据（map_server GetMap + SLAM 实时刷新；GetMap 失败自动改读包内地图文件，默认 /pkg/wheeltec_nav2/map/WHEELTEC.yaml，浏览器直接解析 YAML+PGM，无需 map_server），按 map→fixed frame 的 TF 铺在地面——建图时 fixed frame 填 map 看图最直观；未定位（无 map TF）时地图层自动隐藏。注意：/odom 只是话题名——底盘 TF 树的根是 EKF 发布的 odom_combined（odom_combined→base_footprint→base_link→…），所以 Fixed frame 要填 odom_combined 而不是 odom；填错或底盘（EKF）没启动时，下方状态栏会提示当前 TF 树根，且模型会临时以机器人自身根坐标系显示。

下位机事件（在线/离线 · 低压禁动 · 下发命令解析）

下位机 STM32F407（固件源码见 firmware/KeilSingleChipProject，FreeRTOS；主控板 C63A 原理图见 firmware/C63A原理图_V2.0_2025-06-16.pdf）经串口连接 turn_on_wheeltec_robot，以 20Hz 上行三个数据包：24 字节基础帧（0x7B…0x7D，速度/IMU/电压/使能位）+ 19 字节超声波帧（0xFA…0xFC）+ 8 字节回充帧（0x7C…0x7F）。话题只有帧校验通过才发布，因此话题有数据 = 下位机在线（2 秒无帧判离线）。固件使能 (en_flag) 为固件真实的"允许移动"信号：低压（<20V 且未在回充）/ 急停开关按下 / 软件急停 / 任一驱动器离线或报错，任一条件都会失能（需重编译 turn_on_wheeltec_robot 才有 /robot_enable_flag 话题）。注意：回充模式中固件忽略低压禁动；新固件的自检字段恒为 0（/self_check_data 显示 0x0 属正常）。下发命令解析：驱动把发给下位机的 11 字节控制帧原样发布到 /robot_serial_tx（需重编译），面板按通信协议表解析"模式选择位"（0=速度控制 / 1、2=自动回充 / 3=红外对接速度 / 4=灯带 RGB）与目标速度并校验 BCC——"最近下发指令"实时刷新，命令类型变化时写入事件栏（速度数值变化不刷屏）。

数据链路：下位机固件（firmware/KeilSingleChipProject 的 sensor_ranger.c，FreeRTOS ultrasonic_task 按分组触发各探头防互相串扰）把 A–F 六路测距按 int16 毫米值打进 19 字节超声波帧（0xFA…0xFC，含 BCC 校验，字节 13–16 新固件恒 0）随 20Hz 上行帧发出 → turn_on_wheeltec_robot 校验后发布 /Distance（上排 A–F 原始值）。 俯视图按 ultrasonic_A..F TF 的真实安装位姿（底盘 description launch 按 ROBOT_TYPE 发布）画各路波束： 扇形长度=测距，红<0.3m / 黄<0.6m / 绿=更远， 灰色虚线=无效或超量程（∞）；无 TF 时按均匀扇形近似摆放。 wheeltec_ultrasonic（supersonic_converter）把 /Distance 拆成标准 sensor_msgs/Range（/ultrasonic/A…/ultrasonic/F，注意大写；mini 无 F） 与 /ultrasonic/points 点云（base_footprint 系），供 Nav2 避障消费—— range_sensor_layer 填 A–F 话题，obstacle/voxel_layer 订阅 points。 启动：ros2 launch wheeltec_ultrasonic supersonic+converter.launch.py （wheeltec_nav2 启用超声避障时会自动包含）。"转换节点"以 /ultrasonic/* 话题 3 秒内有数据判在线； 参数（机型/量程/FOV/点云开关）在节点上线时自动读取，仅启动时生效，修改需重启 launch 传参。
